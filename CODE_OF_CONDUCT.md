# Code Of Conduct

We want `MLXR` to be a calm, rigorous, welcoming project.

## Expected Behavior

- be respectful and direct
- assume good intent, but be honest about problems
- focus on the work, not on scoring points
- welcome newcomers and basic questions
- keep technical disagreement constructive

## Unacceptable Behavior

- harassment, intimidation, or personal attacks
- discrimination or exclusionary behavior
- repeated bad-faith disruption
- publishing private or security-sensitive details irresponsibly

## Enforcement

Project maintainers may edit, hide, lock, or remove content that breaks this
code of conduct and may limit participation when needed to keep the project
healthy.

For serious concerns, use a private maintainer contact path if one is
available. If no private path is obvious yet, open a minimal issue requesting
one rather than posting the full details publicly.
