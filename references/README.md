# References

This directory is for local-only cloned upstream repos used for research and implementation guidance.

- `official/` is for first-party upstream repositories.
- `ecosystem/` is for strong community references.

## Definitions

### `official`

`official` means the repo is maintained by the original project authors or first-party organization.

Examples:

- `ml-explore/*`
- `Lightricks/*`

These repos have higher authority as references, but they are still external and local-only here.

### `ecosystem`

`ecosystem` means the repo is community-maintained but high-signal enough to influence design, feasibility, or performance strategy.

These repos are not treated as canonical truth, but they are often useful for current implementation patterns.

These repos are intentionally ignored by Git. They are workspace aids, not project source.
