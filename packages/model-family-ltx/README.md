# model-family-ltx

This package is the first family-adapter target for MLXR.

First implementation slice:

- local `LTX-2.3 Fast` text-to-video
- local `LTX-2.3 Fast` image-to-video
- strict-local text encoding

Out of first slice:

- retake
- audio-to-video
- IC-LoRA parity
- advanced Comfy node parity
